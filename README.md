# Natural Language Processing Practicals

Lab practicals for the Natural Language Processing course, implemented in Python using NLTK, spaCy, Scikit-Learn, BeautifulSoup and WordCloud. Each practical report contains source code, outputs, screenshots, and explanations.

## Topics Covered

* Tokenization
* Stopword Removal
* Stemming
* Lemmatization
* Morphological Analysis
* Corpus Processing
* Word Generation
* N-Grams
* Part-of-Speech Tagging
* Named Entity Recognition
* Semantic Analysis
* Text Similarity
* Word Clouds
* Web Scraping
