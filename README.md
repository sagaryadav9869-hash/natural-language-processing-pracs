Natural Language Processing Practicals
Lab practicals for the Natural Language Processing course, implemented in Python using NLTK, spaCy, Scikit-Learn, BeautifulSoup and WordCloud.
#	Practical	Libraries	Concepts Covered
1	Tokenization, Script Detection and Web Scraping
NLTK, Requests, BeautifulSoup	Sentence Tokenization, Word Tokenization, Script Validation, Web Scraping
2	Stopword Removal and Text Filtering
NLTK	Tokenization, Stopwords, Text Cleaning
3	Stemming and Lemmatization
NLTK	Porter Stemmer, WordNet Lemmatizer
4	Morphological Analysis and Word Generation
NLTK	Prefix, Suffix, Root Word Analysis
5	Brown Corpus Analysis and Text Generation
NLTK	Corpus Processing, POS Tagging, Bigram Generation
6	POS Tagging and Named Entity Recognition (NLTK)
NLTK	POS Tagging, Named Entity Recognition
7	POS Tagging and Named Entity Recognition (spaCy)
spaCy	NER, POS Tagging, Lemmatization, Stopword Removal
8	Unigram, Bigram and Trigram Generation
NLTK	N-Gram Language Models
9	Text Similarity using Bag of Words
Scikit-Learn, NLTK	Vectorization, Cosine Similarity
10	WordNet Semantic Analysis
NLTK WordNet	Synonyms, Antonyms, Hypernyms, Hyponyms
11	Word Cloud Visualization
NLTK, WordCloud, Matplotlib	Text Visualization, Frequency Analysis


Outputs
The practical reports contain source code, outputs, screenshots, and explanations for each NLP concept.
